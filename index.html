01 Privacy Commitment

Giovnex is engineered with an uncompromising approach toward user transparency and digital security. This policy outlines how information is handled to ensure optimal browser speed, high-performance media playback, and responsive artificial intelligence features.

Core Guarantee: Giovnex never sells, rents, or monetizes personal browsing records, search history, or personal file contents.

02 App Integrity & Diagnostic Telemetry

To defend against malicious tampering and ensure smooth operation across diverse hardware configurations, Giovnex collects non-personal hardware metrics:

  • Hardware Metrics: Device model, display resolution, RAM total, battery status, processor cores, and operating system build version.
  • Security Watchdog: Checks runtime integrity (detecting emulated environments, unauthorized debugging, or package hijacking) to protect the application ecosystem.
  • Diagnostic Error Logs: If a technical issue occurs, an anonymized diagnostic report is sent to our secure backend to quickly deploy bug fixes.
  • Unique Instance ID: A randomly generated installation token (UUID) is assigned locally to authenticate update checks and remote configuration.

03 Intelligent AI & Voice Features

Giovnex incorporates high-performance language and image processing engines:

  • Text & Web Summarization: Prompts you submit or webpage articles you summarize are transmitted via encrypted protocols to external neural network processors to generate responses.
  • Voice Transcriptions: When using the voice microphone feature, your speech is converted to text locally or via standard system transcription and is not stored on voice-recording servers.
  • Image Synthesis: Visual generation queries are executed dynamically on secure cloud renderers.

04 Web Browsing & Local Storage

Your web session data remains strictly under your control on your physical device:

  • Bookmarks & History: Saved strictly into device-local encrypted database storage (TinyDB). They are never synced to commercial tracking networks.
  • Incognito Mode: Enabling Incognito immediately isolates your browsing session and purges cookies, cache, web storage, and form records when deactivated.
  • Ad-Shield Engine: An integrated script evaluation engine blocks intrusive tracker scripts, malicious redirects, and aggressive pop-ups.

05 Complete User Data Control

Giovnex provides an immediate, one-click mechanism to wipe your footprints:

System Data Purge: Accessible directly inside the Settings Menu layout, this function instantly resets and wipes all local history, bookmarks, cached files, downloads list, and stored session preferences.

06 Device Permissions

Giovnex requests specific permissions on an as-needed basis strictly to power user-initiated actions:

  • Storage / Media: Required to save downloaded files, documents, and media to the device's shared storage.
  • Microphone: Accessed only when actively triggering speech recognition for search or AI chats.
  • Camera: Accessed only when launching the built-in QR / Barcode scanner utility.
  • Foreground & Media Service: Powers continuous background music and video playback while the screen is locked or idle.
